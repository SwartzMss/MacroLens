# Concept 与 Learning 内容边界（内容治理规范）

本文是 MacroLens 长期维护的内容治理规范，供新内容撰写、审核和共用模板调整时使用。

MacroLens 有两种互补的阅读方式。它们可以引用同一份已核验内容，但回答的问题、组织方式和继续阅读的入口不同。

## 两层内容分别回答什么

| 内容层 | 主要问题 | 适合放什么 | 不重复什么 |
| --- | --- | --- | --- |
| Concept 概念页 | 它是什么？这个数字或术语怎样定义？ | 一句话入口、正式定义、统计范围、单位与时间、数据、来源、关系证据、相关概念 | 不把学习路线写成第二份正文，不在 Markdown 中复制关系图谱说明 |
| Learning 学习路线 | 它如何运作？为什么要接着看下一个概念？ | 学习问题、阅读顺序、路线衔接、假设例子、阶段回顾、回读和探索入口 | 不复制概念定义、指标数据或关系证据；这些内容回到概念页和图谱 |

## 概念页的编写规则

- 用 `intro` 或共用入口先回答“它是什么”，再进入详细说明与统计边界。
- 正文保留必要的定义、统计对象、范围、单位、时间口径、适用条件和来源。
- 数据图表只展示注册表中有来源和更新方式的指标；不为填充页面编造数字。
- 关系由 `data/relations/macro.json` 和 `graphRegistry` 提供。概念页通过关系卡片展示方向、时间关系、适用条件、局限和证据。
- 例子必须标为假设，不能把假设数字写成当期事实。机制表述要写出条件、时滞和可能的反向或中断情况。

## 学习路线的编写规则

- 路线定义只保存编排信息：学习目标、章节、步骤顺序、`focus`、`nextReason` 和路线回顾。
- 每个概念步骤先给本步要回答的问题，再复用概念页的正文、图表口径和来源；不要再维护一份同义定义。
- 需要教学例子时，优先复用概念页中已标注的假设例子；新增例子必须在学习内容中明确标记为假设。
- “相关概念”使用稳定概念 ID 链接；“关系脉络”使用现有图谱和关系卡片，不在路线数据中新增平行关系描述。
- 回顾可以把多个概念放进一个场景，但应说明这是观察框架，不把相关关系写成确定因果。

## 新内容提交前检查

1. 先判断内容要回答“它是什么”还是“它如何运作”。
2. 概念定义、统计口径、指标和来源只保留一个权威位置。
3. 学习路线只增加问题、顺序、衔接和必要的假设例子。
4. 关系新增或调整先更新规范化图谱，再由概念页和学习入口引用。
5. 检查桌面端和手机端的入口文案，确保用户能从一层进入另一层。
