# Concept 与 Learning 内容边界

## 两套独立内容

Learning 与 Concepts 独立撰写、独立组织、独立维护。课程不嵌入概念正文，不以 conceptId 定义步骤，不依赖关联概念列表、概念数据面板或图谱完成解释。读者无需查询概念库就能读懂课程。可以复用基础排版和按钮，但不共享教学正文。

Concepts 继续负责知识对象的定义、机制、口径、数据和关系，本次不改写概念内容。Learn 负责从生活问题开始建立理解。Macro Now 与独立图谱调整不在本批范围。

## 学习写作规范

- 先说明一个熟悉的问题，再一步步解释；不用陌生术语解释陌生术语。
- 需要专业名称时，先讲明白意思，再介绍名字。不省略必要的事实边界。
- 用具体人物和行动，假设故事必须明确标注，不能冒充真实数据。
- 解释变化发生的条件和时间；不把可能的联系写成必然结果。
- 阅读正文应自足。例子、简图和回顾按需要使用，不强制同一模板。
- 文末来源用默认收起的 details，摘要为“正文参考来源”。引用用于核验，不代替独立写作。

## 课程维护

- `src/content/lessons` 保存独立正文；`src/data/courseOutline.ts` 保存主线顺序与开放状态。
- 已开放章节必须有正文；未完成章节只展示大纲，不能生成空课程或计入完成进度。
- 问题探索是独立文章，未来发布时独立于主线进度，读懂所需的背景在文章内说明。
- 新课程使用 `macrolens.course.v1`，不读取、覆盖或换算 `macrolens.learning.v1` 的旧记录。
- 旧 `/learn/:pathId/` 与 `/learn/:pathId/:stepId/` 地址展示迁移说明，不静默跳到新章节。
- 原 `learningPaths.ts` 及旧辅助函数暂留作旧地址兼容资料，不是新课程的内容来源。

## 分批交付

第一批：八章主线大纲、独立课程系统、第一章“经济怎样把我们联系起来？”。其余主线与问题探索明确标注正在编写。

第二批：开放第二章“我们为什么需要钱？”，独立解释交易便利、现金与存款、付款方式和财产的区别。首页按实际开放数量展示；已完成上一章时引导进入尚未读完的章节，已有阅读记录保留。第三章及之后的主线、问题探索继续标为正在编写。

第三批：开放第三章“银行借出去的钱从哪里来？”，独立解释贷款与存款的同时变化、本金还款、付款结算和银行放贷约束。内容应明确区分记账变化、借款人的债务和实际生产，不把贷款增加直接写成财富增加。第四章及之后的主线、问题探索继续标为正在编写。

第四批：开放第四章“借钱贵一点，会改变什么？”，独立解释利率如何改变家庭和企业的借款决定、固定与浮动利率的差别，以及为什么降息不会自动带来更多借款或支出。第五章及之后的主线、问题探索继续标为正在编写。

第五批：开放第五章“东西为什么会越来越贵？”，独立解释个别商品涨价与总体价格上涨的区别、购物篮和个人感受的差异，以及价格上涨速度变慢不等于价格回到原来。第六章及之后的主线、问题探索继续标为正在编写。

第六批：开放第六章“经济为什么时好时坏？”，独立解释销售、生产、招工和收入之间可能形成的相互影响，区分整体波动与不同群体的经历，并说明经济放缓和恢复不会按固定剧本发生。第七章及之后的主线、问题探索继续标为正在编写。

第七批：开放第七章“经济慢下来，能做些什么？”，独立解释中央银行与政府工具影响的环节、政策传导的时间差和需求与供给问题的区别。第八章及之后的主线、问题探索继续标为正在编写。

第八批：开放第八章“怎样看懂经济新闻里的数字？”，独立解释水平、变化量、增速、比较时间、百分点、统计范围、来源和因果判断，完成当前主线的基础阅读方法。问题探索仍然独立于主线进度，后续单独设计和发布。

后续按主线顺序逐章写作，检查前置解释、重复和跳步，再开放阅读。新章节上线时检查上下章导航、继续阅读文案、搜索与进度。问题探索完成后再提供真实阅读入口。

## 验证

检查类型、构建、输出结构与链接；测试新旧进度隔离、异常存储和无效课程 ID。检查桌面和手机上的首页、正文、目录、回顾展开和完成标记。概念页正文、数据和关系保留，旧学习模式不再挂接概念阅读器。
