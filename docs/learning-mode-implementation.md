# 学习模式首版实施记录

状态：2026-09-15 本地实现与验证完成，尚未部署。

## 已实现范围

- 顶部入口为“概念 / 学习 / 搜索”。首页进入学习中心；原 `/topics` 跳转到 `/learn/`，主题详情和概念分类仍保留，宏观关系从学习中心及概念页访问。
- 五条发布路线：从零开始的宏观经济旅程（18 步，八个入门阶段）、钱与银行信用（6 步）、央行如何影响经济（6 步）、如何读懂价格变化（5 步）、开放经济入门（4 步）。共 39 步，包括 5 个回顾页；复用 24 篇不同概念。完整规划中的其他路线尚未发布。
- 每条路线提供目标、前置知识、章节目录、上下步、跳读及回顾。普通概念与学习步骤共用 `ConceptReader`，原正文、图表、口径、来源和关系证据保留。
- 已读需主动标记，可撤销；打开或跳读不会自动完成。进度按路线保存在本机浏览器，支持继续上次位置；未提供账号或跨设备同步。
- 补读页面携带经注册路线校验的返回位置。信贷 → M2 → M1 后仍可返回原路线的信贷步骤。
- 学习步骤使用普通概念 canonical、noindex，并排除于 sitemap 和 Pagefind。搜索仅收录普通概念、学习中心及路线总览，避免重复概念结果。

## 验证

- Node 24；`npm test`：423 项通过；`npm run check`：181 个文件，0 错误、警告、提示。
- `npm run build` 和 `npm run test:output` 通过：87 篇概念、154 个页面、40 个学习步骤；Pagefind 收录 92 页。使用临时 `PUBLIC_SITE_URL` 验证 canonical 和 sitemap，未写入站点配置。
- 浏览器检查 1440、1024、390、320 像素布局，学习入口与 Logo 对齐，小屏无页面横向溢出。实际走通已读、跳读、补读返回、回顾、继续学习、手机目录与 Escape 关闭；旧主题入口能跳到学习中心。
- 禁用脚本时确认正文、目录及普通下一步链接仍渲染，依赖脚本的已读控件隐藏。浏览器自动化的点击方法在禁用脚本后超时，因此该状态下的点击未作成功断言；静态输出验证了上下步链接的目标页面存在。
- 存储拒绝写入、损坏记录、版本变化、无效返回参数与各路线独立进度由逻辑测试覆盖。
- 修复已有内容测试依赖固定发布日期及仅接受 LF 换行的问题，未改动概念正文。

## 后续维护

路线定义集中在 `src/data/learningPaths.ts`。新增步骤使用稳定 ID，并更新章节、目标、回顾和 revision；构建会校验概念引用、步骤顺序与前置闭包。进度加载会剔除已删除的步骤，并保留仍存在的已读记录。

新路线必须完成内容审核后才设为 published，不能把完整规划中的草案直接视为已审核教程。
