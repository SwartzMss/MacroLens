# 数据集元数据可见性 UI 对齐设计

## 背景与范围

Issue #81/#82 已确定 MacroLens 的 V1 元数据可见性政策：概览界面帮助用户快速理解数据，详情页提供核验所需上下文，工程实现信息留在内部。

本次 PR（#83）只对首页 Dashboard、Macro Snapshot 和指标详情页的展示边界与文案做对齐。概念正文、数据抓取、数据校验、数值计算和快照规则本身不变。

## 设计决策

### 展示适配边界

新增 `indicatorPresentationAdapter`，负责把已有 `IndicatorDataset` 和概念页上下文转换为 `IndicatorViewModel`。适配器只做展示语义转换，不重新计算指标数值，不存放指标数据，也不成为包含大量人工配置的总表。

展示模型提供以下用户语言字段：

- `frequencyLabel`：统计频率，例如“月度”“季度”；
- `valueLabel`：最新读数的指标口径，例如“同比”“累计同比”“指数”；
- `changeLabel`：最新读数相对可比上一观测的变化标签，例如“较上一季度”“较上月变化”“较上一个累计期”；
- `comparisonMethod`：详情页使用的完整比较方法说明；
- `coverage`：当前序列的实际起止覆盖期间；
- `sourceLabel` 和来源记录：面向用户的机构名称、官方来源链接、来源发布时间及来源覆盖说明。

其中 `valueLabel` 与 `changeLabel` 保持独立：CPI 的读数口径是“同比”，但 CPI 同比读数的近期变化仍应说明为“较上月变化”，避免把两种比较含义混写。

### Dashboard

指标卡片仅保留快速扫描信息：指标名、统计频率、最新数据期、最新值、指标口径和近期变化。移除来源简称、数据集更新时间、来源展开区和“静态生成 · 无运行时数据请求”说明。

最近变化汇总保留，但其每一项使用 `changeLabel`，不再使用无上下文的“较上一期”。卡片不承载来源、更新时间或长篇方法论。

### Macro Snapshot

移除规则版本号，因为它属于工程审计信息。保留用户有价值的快照更新时间，并使用清晰的“Snapshot updated / 快照更新”语义。

快照事实与信号变化从 `IndicatorViewModel.changeLabel` 取标签，不做页面层的字符串替换。事实内容仍由现有快照逻辑生成，规则解释仍保留为用户理解信号组合的内容。

### 指标详情页

在图表附近新增“如何阅读”区域，按结构化字段展示：

- 指标定义或用户可读指标说明；
- 统计频率；
- 变化口径；
- 数据来源及官方链接；
- 来源发布时间与来源覆盖说明；
- 数据集更新时间；
- 当前数据实际覆盖期间。

原有图表仍使用相同数据序列和图表行为；方法说明保留为用户能理解的口径解释，移除工程 fingerprint、runtime、静态生成和规则版本等实现细节。

## 数据流与错误处理

页面从 `getDashboardIndicators()` 或详情页的 `IndicatorDataset` 获取原始数据，经 `indicatorPresentationAdapter` 生成展示模型后传给 Dashboard、Snapshot 和详情元数据组件。近期变化数值沿用现有 domain summary；适配器只负责标签、频率、来源名称和覆盖期间的展示转换。

数据集为空时继续沿用现有 `deriveObservationSummary` 的错误；缺少可比上一观测时，变化值显示为 `—`，变化说明不得虚构。来源列表为空时详情页显示明确的“来源信息待补充”，不把内部字段作为替代来源。

## 测试策略

先写失败测试，再实现：

1. `indicatorPresentationAdapter` 单元测试验证 GDP、CPI、PMI 和累计同比指标的频率、读数口径、变化标签、比较方法、来源名称与覆盖期间。
2. Dashboard 边界测试验证卡片不包含来源、更新时间、静态生成说明，且包含最新值、最新期间和 `changeLabel`。
3. Snapshot 边界测试验证不包含规则版本，保留快照更新时间，并使用指标专属变化标签。
4. 详情页边界测试验证存在“如何阅读”、来源、更新时间、覆盖期间和比较方法，同时不暴露 runtime、fingerprint 或规则版本。
5. 运行现有完整测试、Astro 检查、静态构建和 `git diff --check`。

## 非目标

- 不修改任何数据抓取、规范化、校验、写入或数值计算逻辑；
- 不改变宏观快照的判断规则或规则解释内容；
- 不公开工程审计字段；
- 不新增开发者/debug dashboard；
- 不把展示适配器扩展为指标数据或规则配置的集中存储。
