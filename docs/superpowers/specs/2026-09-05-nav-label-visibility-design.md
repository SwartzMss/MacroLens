# 导航标签可见性调整设计

## 目标

提升首页及全站右上角“概念 / 主题 / 搜索”导航标签的可读性，让它们在当前布局中更醒目，同时不改变导航结构、间距或响应式行为。

## 方案

在 `src/styles/global.css` 的 `.nav a:not(.brand)` 规则中，将导航标签字号从 `14px` 调整为 `16px`，并增加 `font-weight: 700`。品牌文字保持现状，导航间距与移动端布局不变。

## 验证

运行 `npm run check`，确认 Astro、TypeScript 与模板检查通过；再检查工作区差异和最终提交是否已与 `origin/main` 一致。
