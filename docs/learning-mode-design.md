# MacroLens 学习模式方案

状态：首版已实现并完成本地验证，尚未上线。设计于 2026-09-14，依据 `origin/main` 的 `fb19627` 盘点；实施记录见 [learning-mode-implementation.md](learning-mode-implementation.md)。以下保留完整规划，首版之外的路线仍为草案。

## 1. 要解决的问题与推荐决策

读者从首页的学习路径进入一个概念后，无法知道自己处于哪一步、下一篇是什么，也无法在补充阅读后方便地回到原路线。增加一份概念目录不能解决这个问题。

推荐把 MacroLens 的主要使用方式明确为：

- **查概念**：带着一个名词来，快速找到定义、解释、数据和来源。
- **按路线学习**：带着一个问题来，沿着明确顺序阅读、补基础、回顾和继续。
- **查关系**：理解两个对象之间的联系、适用条件和证据，作为前两种阅读方式的辅助。

产品入口统一使用“学习”，进入路线后显示“正在学习”。不做一个脱离路线的全站“学习模式”开关：不知道读哪条路线时，开关本身没有明确含义。

顶部导航建议为 **概念｜学习｜搜索**，Logo 继续返回首页。主题保留为内容分类；宏观关系保留为参考工具，移到学习中心的辅助入口和概念页的关系区。主页的宏观观察功能继续保留。

第一版的最小完整体验是：**选路线 → 看目标和目录 → 开始阅读 → 随时知道位置 → 补充阅读后返回 → 标记已读并继续 → 回顾 → 下次接着读**。

## 2. 当前基础与真实缺口

| 已有实现 | 盘点结果 | 本次如何处理 |

| 阅读入口 | 85 篇有 `intro`；信贷和货币政策使用专门入口组件 | 继续复用，不在学习页再写一遍概念定义 |

| 主题 | 15 个主题；主题成员可跨领域，一个概念可属于多个主题 | 保留分类元数据，避免再扩展一套并列目录 |
| 主题排序 | `sortTopicConcepts` 按主题内前置关系分层，再按 `order` 和 ID 排序 | 可辅助审核，但不能直接当作教学路线 |
| 首页路径 | 4 条、每条 3～4 个概念，点击直接跳普通概念页 | 替换为同一学习路线注册表生成的入口 |
| 概念页目录 | 桌面右侧本页目录；手机顶部折叠目录 | 学习时在同一导航位置加入路线，避免多条侧栏和多层吸顶 |
| 宏观关系 | `/graph` 是按节点浏览关系卡片及证据的浏览器，并非必须重建的大型关系图 | 保留页面、关系数据、条件与证据；调整入口级别 |
| 阅读进度 | 无学习路线状态和上下篇 | 新增本地进度及路线导航 |

具体缺口：现有首页“钱是怎么创造出来的”从信贷开始，但信贷的前置是 M2，M2 的前置是 M1，M1 的前置是 M0。货币政策路线虽然有四篇，却没有处理信贷的这些前置知识。主题中的 `prerequisites` 也不是一份已经审核完毕的课程大纲。

## 3. 信息架构与旧入口处理

| 页面或入口 | 新定位 | 首版处理 |
| --- | --- | --- |
| `/` | 观察与学习的共同入口 | 主视觉提供“开始学习”和“看当前宏观状态”；原学习卡片改为真实路线入口，不展开第二份完整目录 |
| `/concepts` | 概念库 | 保留三种筛选；主题仍是筛选维度 |
| `/concepts/[id]` | 普通查阅 | 保持现有阅读结构；有已发布路线时，在合适位置提供“在路线中学习”入口 |
| `/learn` | 学习中心 | 继续学习、入门主线、专题路线、辅助关系浏览入口 |
| `/learn/[pathId]` | 路线总览 | 目标、建议基础、完整目录、开始或继续学习 |
| `/learn/[pathId]/[stepId]` | 路线阅读 | 引用已有概念正文，附加路线导航、步骤目标和上下篇；也容纳路线回顾步骤 |
| `/topics` | 旧主题总入口 | 学习中心正式启用后转向 `/learn`，更新站内链接；实现时核对当前静态站点的重定向配置 |
| `/topics/[id]` | 兼容旧链接的主题目录 | 暂时保留并从顶部导航移出；有相关已发布路线时提供学习入口，不把未完成路线包装成课程 |
| `/graph` | 关系浏览器 | URL、节点选择、关系卡片和来源均保留；从学习中心和概念关系区可达 |

主题与路线是多对多关系，不要求 15 个主题恰好对应 15 条路线。比如“居民部门”和“劳动力市场”可以合成一条分章路线；“货币政策”可以借用信用主题中的信贷概念。

首版不删除旧主题详情，避免在没有完整承接内容时损坏收藏和外部链接。以后若归并到概念筛选页，需先实现并验证可分享的筛选 URL；当前 `concept-filters.ts` 尚未从 URL 读取筛选状态，不能直接假定 `/concepts?topic=…` 已经有效。

## 4. “完整路径”如何组织

完整的标准是目标、基础、顺序、衔接和回顾齐全；不是强迫用户读完全部 87 篇。

### 4.1 一条宏观入门主线

建议 ID：`macro-foundations`。主线按章组织，包含 **22 篇概念阅读 + 1 个全程回顾，共 23 步**。第一次只展示“从第 1 章开始”，其余章节可展开或直接进入，不用一开始面对 23 张卡片。

| 章节 | 学习问题 | 阅读顺序 |
| --- | --- | --- |
| 1. 经济活动 | 新闻里的增长和景气在说什么？ | GDP → 社会消费品零售总额 → PMI |
| 2. 价格 | 居民端与生产端的价格分别怎么看？ | CPI → PPI |
| 3. 就业与收入 | 经济变化如何体现在工作和收入上？ | 就业 → 城镇调查失业率 → 工资与劳动报酬 → 居民人均可支配收入 |
| 4. 钱与信用 | 货币口径和银行贷款是什么关系？ | M0 → M1 → M2 → 人民币贷款与信贷 |
| 5. 货币政策 | 央行怎样影响融资条件？ | 货币政策 → 政策利率 → LPR |
| 6. 财政 | 政府如何参与经济活动？ | 财政政策 → 财政支出 → 政府债务 |
| 7. 对外联系 | 汇率、出口和进口分别回答什么？ | 汇率 → 出口 → 进口 |
| 全程回顾 | 能否区分活动、价格、收入、融资、政策和外部流量？ | 路线专属回顾，不新增“概念”条目 |

这是一条建议阅读顺序，不表示相邻概念有直接因果关系。各章提供一个学习目标和一句衔接，章节本身不是另外一篇重复正文。

主线里的财政收入、赤字、居民消费与储蓄、国际收支结构等留到专题展开。各章结尾给出相关专题入口，不以“完整入门”为名承诺覆盖所有细节。已读过的文章仍显示在所在步骤，可自行略过或复习。

### 4.2 专题路线全貌

下面是覆盖现有内容的路线草案，编号用于本文讨论，不是概念编号。核心列表是阅读顺序；延伸列表不计入必读进度。超过 6 篇的路线拆成每章约 3～4 篇。进入前已有知识由路线总览明确说明，不通过完成记录强制锁定。

| 编号与路线 | 核心阅读顺序（稳定概念 ID） | 延伸阅读（稳定概念 ID） | 路线外建议基础 |
| --- | --- | --- | --- |
| T01 钱与银行信用 | `m0` → `m1` → `m2` → `credit` → `social-financing` | `credit-spread`, `mortgage` | 无 |
| T02 央行如何影响经济 | `monetary-policy` → `policy-rate` → `interbank-rate` → `lpr` → `credit`，最后回顾 | `omo`, `rrr`, `real-interest-rate` | M2 与贷款创造存款的直觉；提供 T01 补基础入口 |
| T03 如何读懂价格变化 | `cpi` → `ppi` → `core-cpi` → `price-transmission` | `inflation-expectations`, `gdp-deflator`, `real-interest-rate`, `phillips-curve` | 核心无；延伸项分别提示 GDP、产出缺口等基础 |
| T04 如何观察经济活动 | `gdp` → `industrial-production` → `retail-sales` → `fixed-asset-investment` → `pmi` | `capacity-utilization`, `industrial-profits`, `inventory-cycle`, `leading-indicators`, `output-gap` | 核心无 |
| T05 工作、收入与消费 | 第一章：`employment` → `labor-force-participation` → `unemployment-rate` → `youth-unemployment`；第二章：`wages` → `disposable-income` → `income-expectations`；第三章：`household-consumption` → `household-saving-rate` → `propensity-to-consume` | 可回到 T04 对照居民消费支出与社零口径 | 无；后两章包含进阶概念，应保留难度标识 |
| T06 长期增长的基础 | `gdp` → `productivity` → `working-age-population` → `labor-force-participation` → `potential-output` → `output-gap` | `total-factor-productivity`, `demographic-dependency-ratio` | 无，首步可复习 GDP |
| T07 财政如何影响经济 | `fiscal-policy` → `fiscal-revenue` → `fiscal-expenditure` → `fiscal-deficit` → `government-debt` | 进一步进入 T08 | 无 |
| T08 地方财政与融资 | `fiscal-policy` → `local-government-finance` → `land-transfer-revenue` → `local-government-debt` → `local-government-special-bonds` → `lgfv` | `land-market` | 无；首步可复习财政政策 |
| T09 住房与房地产 | `property-sales` → `house-price-index` → `mortgage` → `real-estate-investment` → `land-market` | `lpr`, `land-transfer-revenue` | 核心无；延伸贷款定价接 T02、地方收入接 T08 |
| T10 如何区分各种利率 | `policy-rate` → `interbank-rate` → `government-bond-yield` → `yield-curve` → `credit-spread` → `real-interest-rate` | `lpr` | 货币政策与 CPI；提供 T02、T03 基础入口 |
| T11 汇率如何理解 | `exchange-rate` → `usd-cny` → `usd-cnh` → `rmb-exchange-rate-regime` → `effective-exchange-rate` → `cfets-rmb-index` | `interest-rate-parity`, `carry-trade`, `impossible-trinity`, `capital-controls`, `foreign-exchange-reserves` | 核心无；利率平价与套息等为进阶阅读，不作投资策略 |
| T12 贸易与国际收支 | 第一章：`exchange-rate` → `exports` → `imports` → `trade-balance`；第二章：`balance-of-payments` → `current-account` → `financial-account` | `trade-volume-and-price`, `terms-of-trade`, `capital-account`, `cross-border-capital-flows` | 无；需说明海关贸易与国际收支口径不同 |
| T13 对外资产与负债 | `balance-of-payments` → `international-investment-position` → `external-debt` → `reserve-assets` → `net-foreign-assets` → `foreign-exchange-reserves` | 回到 T12 对照流量与存量 | 无；包含进阶概念，重点保持存量、流量和估值变化的边界 |

路线名称用读者问题或熟悉的领域表达；产品界面显示中文概念名，不显示 ID。上表为后续路线编辑提供完整内容位置，不能把未审核的 13 条路线一次性标为可学习。

前置审核分两层：机械检查现有 `prerequisites`，人工检查阅读是否真的能接上。前置不在本路线前序步骤时，必须列为进入基础或可返回的补充阅读。延伸阅读也执行同样规则，例如菲利普斯曲线要先连接通胀预期和产出缺口，不能从 CPI 直接暗示其已经具备所有基础。

## 5. 首条样例：央行如何影响经济

建议 ID：`monetary-transmission`。学习目标是分清政策操作、资金价格、贷款定价和信用变化，能解释传导受哪些条件影响。共 **5 个概念步骤 + 1 个回顾步骤**。

| 步骤 | 本步重点 | 连接下一步的理由 |
| --- | --- | --- |
| 1. 货币政策 | 分清目标、工具、操作和结果 | 从政策框架进入一个具体的利率信号：政策利率 |
| 2. 政策利率 | 分清央行政策利率与贷款合同利率 | 政策信号如何体现在市场资金价格上？接着看 DR007 / R007 |
| 3. 银行间资金利率 | 理解实际交易形成的资金价格，区别于政策利率 | 资金成本只是贷款定价的一个因素，接着看 LPR |
| 4. LPR | 分清参考报价、实际贷款利率与重定价时间 | 报价变化后是否真的形成贷款，需要继续看信贷 |
| 5. 人民币贷款与信贷 | 区分余额、增速和新增贷款，并理解银行供给与借款需求的条件 | 回顾从政策到信用的几个环节，检查哪些推断不能直接成立 |
| 6. 路线回顾 | 用三个问题检查是否建立基本联系；提供可展开的解释与回读链接 | 可以复习本路线，或进入经济活动、货币信用等专题 |

与旧首页四步路线相比，增加资金市场这一环节和独立回顾；这是学习顺序，不是声称贷款定价只经过这一条单线传导。第 3 步当前标为进阶，需要在内容审核中确保开头足够易懂，保留后面的期限与口径说明。

### 5.1 信贷前置如何处理

路线总览提示：“建议先知道 M2 与银行存款的关系；不熟悉可以先补基础。”提供 T01 的入口，不要求先通过考试或完成整条路线。

第 5 步出现简短的“需要补基础？M2 与贷款创造存款”入口。补读保留返回第 5 步的导航，不把 M0、M1、M2 强行插入原路线，也不把补读自动计成原路线进度。底层前置关系仍按 M0 → M1 → M2 逐步提示。

### 5.2 回顾内容样例

- “政策利率下调，是否意味着所有存量贷款当天等幅下调？”展开后提示区分 LPR、合同加减点及重定价安排，回读政策利率、LPR。
- “市场资金较充裕，是否足以判断新增贷款一定增加？”展开后提示结合银行约束、借款需求与偿还能力，回读货币政策、信贷。
- “要继续观察传导，可以分别看哪些环节？”按照政策信号、资金市场、贷款报价、信用和经济活动列出回读入口，保留时间差、口径和局限。

这些是待审核的教学提示，依据已有货币政策、政策利率、LPR 和信贷正文编写。路线回顾的每个解释必须指向具体原文或关系详情及其证据；不新建一份重复的关系证据清单。若增加新的事实或实证判断，需要独立核对来源。

首版不用真实最新数据出题，不给分、不宣称“掌握”，不需要题库系统。教学数字如确有必要，必须明确标为假设。

## 6. 页面设计与交互

### 6.1 学习中心

从上到下：

1. 栏目标签“学习”、标题“按一条路线理解宏观经济”、一句简短说明。
2. 仅在有记录时显示最近一条“继续学习”，包括路线名、章节、上次位置和已读步数。
3. 入门主线的突出入口；展示章节轮廓，默认突出第一章。
4. 已发布专题路线，每张卡片显示问题、学习目标、基础要求、步数和开始按钮。
5. 低优先级入口：“想查一个名词？去概念库”“想查联系？浏览宏观关系”。

没有学习记录时不显示空进度卡。首版不做复杂筛选、打卡日历、推荐算法或未完成课程的大量占位卡片。

**对齐基准：** 页面外层使用站点 `.shell`，栏目标签、页面标题与页头 MacroLens 左边缘对齐。正文需要限宽时只约束内层，不把整个栏目容器缩窄。桌面和手机都核对真实坐标，避免重复搜索页出现的问题。

### 6.2 路线总览

显示路线名、读完能回答的 2～3 个问题、建议基础、目录和一个主按钮。长路线按章折叠，显示各章步数；不标未经测量的“预计 20 分钟”。

目录明确区分未读、当前、已读，并同时使用文字或图标，不只靠颜色。全部步骤可点击，允许直接跳读。延伸阅读单列在核心目录之后。

按钮规则：无记录时为“开始学习”；有记录时为“继续：上次步骤”；全部标为已读时为“查看回顾”，同时可重新阅读。路线目录始终可见，不强制依赖本地记录才能开始。

### 6.3 学习阅读页

页面沿用现有概念页的正文和视觉样式，增加有限的路线信息：

- 概念标题上方显示“学习 / 路线名”和“第 2 / 6 步”；不要把进度写成知识掌握程度。
- 标题下最多加一句本步关注点，只有它补充了路线语境时才显示；不重复 `intro`、副标题或专用入口。
- 桌面继续使用两栏：正文 + 右侧约 240px 导航。右侧优先展示“本路线”，其下“本页目录”可折叠；不用左路线、正文、右目录三栏。
- 手机复用现有目录位置，显示“第 2 / 6 步 · 目录”，展开后区分“路线步骤”和“本页章节”。只保留一层阅读导航吸顶，展开后可滚动、可收起、键盘可操作。
- 正文保持先理解、详解、相关数据及口径的顺序。关系证据与来源继续保留，不为缩短路线删除统计边界。已有信贷、货币政策专用入口继续复用。
- 在正文及数据/来源模块之后、反馈与继续探索之前设置路线导航。给出“上一步”和下一步标题，并用一句话说明为什么接着读它。
- “退出学习模式”回到同一概念的普通页面；路线名链接回路线总览。两者含义明确，不另设重复的返回按钮。

普通概念页不因浏览器保存了某条路线，就自动进入学习模式。搜索进入仍然是普通查阅；只有用户从路线入口进入时才有明确路线上下文。

### 6.4 “已读”和“下一步”

默认打开页面只更新“上次位置”，不更新已读。提供可撤销的“标为已读”与普通下一步链接；启用脚本时可增强为“已读，继续下一步”的主操作，同时保留“直接下一步”。

不因滚动到底、停留时间或点击下一篇，就声称读者已经学会。已有明确已读状态的步骤可以重新阅读，并能撤销已读。

没有 JavaScript 时，路线目录、文章内容和上下篇链接仍正常使用，只不保存进度；不会出现点击“已读”却没有记录的假成功提示。

### 6.5 临时查阅与返回

| 动作 | 期望行为 |
| --- | --- |
| 点击同一路线中的概念 | 跳到该路线对应步骤，保留路线；不自动把中间步骤标为已读 |
| 点击其他概念或补基础 | 普通查阅，并在有合法返回上下文时显示“返回路线 · 第 N 步”；原路线的上次学习步骤保持不变 |
| 从补充页再次补基础 | 延续最初的路线返回点，不形成越来越深的返回链 |
| 点击外部官方来源 | 保留正常链接行为，不更改学习进度 |
| 浏览器后退/前进、刷新或复制步骤地址 | 恢复 URL 指定的同一路线、同一步；本地记录不能覆盖明确 URL |
| 两条路线引用同一概念 | 各自保留步骤目标和路线进度；不得跨路线自动跳步 |

首版只恢复到步骤或合法章节锚点，不承诺精确恢复像素滚动位置。补充查阅的返回提示可以渐进增强；禁用脚本时普通链接与浏览器后退仍可用。

### 6.6 回顾与继续

回顾是路线内的正式末步，含少量可展开的问题解释和回读链接。只有全部核心步骤标为已读后才显示“已读完这条路线”；直接跳到末页只算读到回顾，不自动完成全程。

延伸阅读不进入核心进度分母，路线结束后也不强迫用户进入其他路线。跨路线遇到已读概念，首版仍让用户自行决定复习或跳过，不设置“学会过，所以免修”。

## 7. 内容复用与数据设计

### 7.1 选用独立静态学习 URL

采用 `/learn/[pathId]/[stepId]`，而不是只在普通概念地址上加一个必须依靠脚本解释的模式参数。路线目录、标题、上下篇可在构建时生成；刷新、分享以及禁用脚本仍能阅读。

两类地址必须复用同一内容组件、同一 Markdown 和同一指标/关系注册表。学习页只是不同阅读外壳，不复制一份概念内容。不对全部概念与全部路线做笛卡尔积生成，只生成实际存在的步骤。

学习中心与路线总览正常索引；概念型步骤页面标为 `noindex`、从 sitemap 排除并通过 canonical 指向普通概念页。步骤页整体从 Pagefind 排除，避免搜索出现多份相同文章；回顾步骤同样从搜索和 sitemap 排除，canonical 使用自身地址。当前 `BaseLayout` 仅有 `noindex`，实现时需增加受控 canonical 参数，并在 sitemap 配置中明确过滤步骤页。

### 7.2 最小路线模型

建议建立 `src/data/learningPaths.ts`，只保存编排和路线特有信息：

| 字段 | 用途 |
| --- | --- |
| `id`, `title`, `description` | 路线身份、问题和简要介绍 |
| `status: draft / published` | 草稿不进入公开列表、不生成公开学习步骤 |
| `revision` | 记录路线结构或教学目标的实质调整 |
| `topicIds` | 关联已有主题，允许多对多 |
| `outcomes` | 学完希望读者能回答的问题 |
| `assumedConceptIds` | 路线外建议基础，必须有可返回的补读入口 |
| `chapters` | 可选分章；引用稳定步骤 ID，不另存重复正文 |
| `steps` | 顺序列表，步骤类型为 `concept` 或 `recap` |
| `extensionConceptIds` | 延伸阅读，与核心进度分开 |

概念步骤保存 `id`、`conceptId`、可选 `focus`、`nextReason`；回顾步骤保存稳定 ID 和路线专属内容引用。标题、图表、来源、概念难度从现有内容取得。回顾内容建议放入单独的学习内容目录，不能混入概念库增加“概念数”。

构建检查：ID 唯一、所有引用存在、步骤至少一个、章节不重复或漏掉步骤、公开路线不依赖草稿、`concept` 步骤不重复、前置知识已在之前出现或被显式列入基础。检查前置依赖闭包；未覆盖时列出缺口，编辑者决定补步或明确基础，不自动插入一串课文。

现有 `order` 继续用于概念目录；`topics` 继续分类；`prerequisites` 继续表达基础关系；学习路线顺序由 `steps` 明确编排，不能互相取代。

### 7.3 本地进度

使用一个有版本的本地存储结构，按 `pathId` 保存：路线修订号、`lastVisitedStepId`、`completedStepIds` 和最近访问时间。状态使用稳定 ID，不能使用列表下标。

- 存储不可用、内容损坏或版本不兼容时，阅读和链接继续工作；只在用户尝试保存失败时给简短提示。
- 重排步骤保留仍然存在的已读 ID；删除步骤时清理对应记录；新增必读步骤保持未读，并重新计算已读数量。
- 实质更换某一步学习目标时更换步骤 ID 或显式迁移；只更新宏观数据不清空已读状态。
- 续读优先使用有效的上次位置；失效时回到第一个未读步骤；全部读完时进入回顾。
- 只在明确操作时清除当前路线记录，不提供容易误触的全站清空按钮。
- 进度仅保存在本机浏览器，不做账号、跨设备同步或云端学习档案。分享链接只分享阅读位置，不分享个人进度。

文章反馈仍使用原概念 ID，避免同一文章被拆成多份反馈。路线回顾不冒用概念 ID。现有访问统计不等于学习完成统计，首版不增加上报阅读进度的埋点，也不把 `/learn` 访问自动当作 `/concepts` 访问。

## 8. 具体改动边界

| 位置 | 预计工作 |
| --- | --- |
| `src/data/learningPaths.ts`、对应路线验证逻辑 | 路线唯一数据源及引用/顺序检查 |
| `src/pages/learn/index.astro` | 学习中心 |
| `src/pages/learn/[pathId]/index.astro` | 路线总览 |
| `src/pages/learn/[pathId]/[stepId].astro` | 构建实际路线步骤 |
| `src/pages/concepts/[id].astro` 与新的共用正文组件 | 抽出当前文章渲染，普通页与学习页共用；保留锚点、专用入口、图表与来源 |
| 新的学习导航组件及脚本 | 路线/页内目录、上下篇、本地进度、补读返回 |
| `src/layouts/BaseLayout.astro`、`astro.config.mjs` | 顶部入口、受控 canonical、sitemap 过滤 |
| `src/data/home.ts`、首页学习卡片和 Hero | 移除首页独有的路线配置，改读已发布路线；保留观察功能 |
| 主题总入口及详情 | 入口迁移、旧链接兼容与相关路线链接 |
| 学习样式 | 沿用现有配色、字号、`.shell` 和响应式规范，不引入新 UI 框架 |

补读返回上下文仅接受注册表中的 `pathId` / `stepId`，不得接收任意返回 URL。普通概念页可以通过验证后的查询参数增强一个返回提示，不能据此改写正文或把普通查阅记录成路线步骤完成。

首版不新增图谱编辑器、推荐模型、宏观预测、投资建议、账号、积分、考试或独立课程管理后台；也不重写所有概念正文。只有路线审核发现真实阅读断点时，才局部补充解释并保留精确定义。

## 9. 实施顺序与首版交付口径

先设计全貌，随后分可独立审阅的工作提交。阶段 A 是内部验证，阶段 B 才对外切换导航。

| 阶段 | 交付 | 完成条件 |
| --- | --- | --- |
| 前置整理 | 修复已知的主线测试阻塞 | 在独立维护提交中处理把概念更新时间写死为旧日期的测试；不要混进内容或布局改动 |
| A1 共用阅读基础 | 抽取正文渲染与路线模型，普通页表现不变 | 有图表、无图表、专用入口及进阶概念的输出和锚点一致 |
| A2 单路线贯通 | T02 的五篇 + 回顾，完整目录、上下篇、进度、补读返回 | 从开始到结束无需手动返回概念目录找下一篇；发布前先用预览验证，不切全站入口 |
| B 正式学习入口 | 发布入门主线 + T01/T02/T03；首页、顶部导航和旧主题入口衔接 | 四条路线均完成基础审核、步骤衔接和回顾；去除首页旧的独立路径配置 |
| C 分专题扩展 | 按上述内容路线图逐条完成其余专题 | 每条路线单独审核再发布；不用未完成路线充数 |

阶段 B 是建议的第一版对外交付范围：既有完整入门方向，也有货币、信用、政策和价格的专题深读。只有完成 A 时应称为“单路线试用”，不能宣称全部概念已有完整课程。13 条专题路线是内容建设规划，不是首版必须一次发布的数量目标。

当前主线已知测试阻塞是 `tests/external-stocks-content.test.mjs` 对 `updatedAt` 固定断言旧日期；这不属于学习模式设计，但实施前要处理，避免再次把构建通过误报成全部 CI 通过。实际开发开始时重新核对主线状态。

本方案没有改变概念的前置定义。正式配置路线时，`assumedConceptIds` 中的前置闭包也要可查阅：例如“建议知道 M2”可以作为进入条件，但补读界面仍需允许沿 M1、M0 回溯，不能只在配置里列一个 ID 就认为断点已经解决。

## 10. 验收标准

### 阅读任务

- 新读者能从首页进入学习中心，找到入门路径，并在第三步看出当前章、当前步骤和下一篇。
- T02 从货币政策一路读到回顾，始终有明确下一步；没有强制打开关系浏览器或概念目录的中断。
- 在信贷步骤补读 M2，进一步补读 M1，再返回时仍回到原路线的信贷步骤。
- 直接通过搜索进入 M2，不会被已有进度强行带入学习模式；可以自主选择一条引用它的路线。
- 同一概念位于入门与专题两条路线时，分享、刷新、后退、前进都保留当前路线语境。
- 跳到最后一步不会把前面全部标为已读；延伸阅读不会改变核心进度分母。
- 禁用脚本或拒绝本地存储后，文章、目录、上下篇仍可用；不会阻挡阅读。

### 布局与内容

- 1440px、1024px、390px、320px 代表宽度检查；栏目标签和 Logo 左边缘一致，无横向溢出。
- 学习页只有一套桌面阅读导航或一层手机目录栏；键盘焦点和锚点不被吸顶栏遮挡。
- 长路线目录在小屏可展开、滚动与关闭；完成状态不只用颜色表达。
- 普通概念页和学习页的正文、图表、单位、来源、关系证据保持一致；路线学习目标不重复概念定义。
- 验证 M2（通用入口+图表）、货币政策（专用入口+无图表）、信贷（专用入口+图表）、银行间资金利率（进阶+无图表），并至少检查一篇不属于首发路线的普通概念页。

### 技术验证

- 模型、组件改动运行 `npm run check`；页面改动运行 `npm run build` 和 `npm run test:output`；引用校验、进度迁移、补读返回和导航逻辑运行有针对性的测试。
- CI 使用项目要求的 Node 版本，所有必要检查实际通过；测试预期使用固定的教学夹具或结构约束，不依赖实时日期或最新指标数值。
- Pagefind 对同一概念只返回普通概念页；学习中心和路线总览可被检索，步骤页不重复收录。
- 生产站点地址存在时验证 canonical 与 sitemap；旧主题 URL 可访问或正确跳转，所有首发按钮只指向已发布路线。

## 11. 设计阶段结论

采用“概念查阅 + 路线学习”两种主入口，主题分类继续支持内容组织，关系浏览器保留为参考。学习内容复用概念正文，以显式路线、前置知识处理、连续导航和本地进度补齐阅读体验。

实施先把 T02 全程走通，再以入门主线和三个专题完成第一版；其余概念按内容路线图逐条接入。本文没有修改功能代码，也没有把路线草案作为已经审核完成的宏观结论发布。
